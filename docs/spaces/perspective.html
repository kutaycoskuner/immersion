II. description · perspective

A projection is a transformation too

Like translation, scaling and rotation, a projection is a transformation: a 4×44 \times 44×4 matrix that takes every point somewhere, here onto the screen, the plane z=0z = 0z=0 (shaded in the viewport).

The difference: it throws a direction away. Every point along that direction lands on the same spot, so the result cannot be undone -- the matrix has no inverse. A translation only moves things; a projection flattens them.

In graphics this is the step from 3D to 2D: local to world and world to camera are transformations that can be undone, the projection to the screen is the one that cannot.

The cube is centred at the origin. The eye sits at (0,0,d)(0, 0, d)(0,0,d) in front of the screen (the white dot); type ddd in the matrix panel. We follow a point ppp.

Self experimentation and comprehension

the near face of the cube (z=1z = 1z=1) becomes bigger than the far one (z=−1z = -1z=−1): the projected cube looks like a box seen from the front

move the eye away (bigger ddd): the difference shrinks, it looks more and more orthographic
